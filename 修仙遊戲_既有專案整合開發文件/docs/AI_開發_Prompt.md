# AI 開發 Prompt（重建版）

> 2026-11-19：原檔與 Git 保存版本均損壞。本文件依現行主 Prompt、需求規格及代理規範重建，並非歷史原文。損壞原檔保存在 `G:\git\autoGame-backup-before-repair-20261119`。

主要開發流程以 [AI 開發主 Prompt](../../prompt/AI_開發_Prompt.md)、[需求規格](../../document/規格/修仙遊戲_開發需求規格.md) 及 [AGENTS.md](../../AGENTS.md) 為準。使用者目前指示優先；待確認事項不可當成已確認規格。

每次開發先核對現況與進度三檔，限定已授權範圍，再以最小變更完成程式與必要設定。固定玩法數值依現行規範保存於 config，透過既有設定快照使用；驗證建置、相關測試並記錄實際結果。未執行的驗證須標示未驗證，未通過不得標記完成。

玩家僅直接控制指定角色，NPC 自主決策；玩家與 NPC 共用行動規則。AI 依有限資訊規劃，經共用驗證及執行流程改變世界。模擬時間由固定 Tick 與事件推進，不以畫面 FPS 作為模擬時鐘。

階段與驗收請見 [進度總表](../../開發進度/開發進度總表.md)、[重構計畫](../../docs/方案/既有專案_重構計畫.md) 及 [驗收入口](../../docs/驗收/README.md)。原文中未能從上述來源核實的其他內容不在本重建版中。
