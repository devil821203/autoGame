# 組織與聚落獨立場景：首版

更新：2026-10-18。限定先製作場景；人口、政治、占地擴張、主建築升級及內部施工未在本次實作。

## 如何觀看

1. 用 Godot 4.3 .NET 開啟 `src/Presentation/project.godot`，F5執行。請先保存目前世界。
2. 按「六角世界／領地測試」建立新情境，選「六角世界」頁。舊存檔不會自動補入新場景。
3. 在地圖選入口格，從場景下拉選單選擇名稱；先旅行至該格、推進Tick抵達，再按「進入選取場景」。
4. 進入「獨立場景」頁後，可點主建築查看等級、點可用空地查看格子，按上方或場景山門的「返回六角世界」離開視圖。若畫面超出視窗，使用外層捲軸向下查看。

| 入口格 | 獨立場景 |
|---|---|
| `(2,3)` | 青雲國治所、青雲幫堂口、青雲鎮（三個獨立入口） |
| `(4,2)` | 青雲宗駐地 |
| `(3,5)` | 黑風寨據點 |
| `(1,5)` | 柳溪村 |
| `(8,3)` | 望川城（新增城市場景測試聚落） |

青雲宗場景提供既有「宗門任務」「宗門設施與兌換」入口；青雲鎮提供既有市場介面。既有操作仍依原規則驗證，沒有搬移藥園／煉丹房或取消它們的旅行成本。其他場景目前提供主建築與建築格呈現，不宣稱已完成各組織特色服務。

## 實際製作

- 七份Node2D場景資源：`src/Presentation/Scenes/Areas/`下的`StateSite`、`SectSite`、`GangSite`、`StrongholdSite`、`VillageSite`、`TownSite`、`CitySite.tscn`。
- `SiteCourtyard.cs`：各類色塊地面、主建築、樹木／道路、可點擊出口及建築格。
- `SiteScenePanel.cs`：依獨立場景ID載入資源，顯示主建築等級與可用格，提供返回及已有服務入口。
- `HexMapPanel.cs`／`Main.cs`：同一世界格的多入口選單、抵達檢查與場景頁接線；`HexMapCanvas.cs`補城市標記。
- `src/Domain/SceneSites.cs`、`HexMapState.Sites`：保存各場景ID、組織關聯、入口、主建築名稱／展示等級及建築格清單，不建立第二份庫存。
- `HexWorldScenario.cs`／`HexIntegrity.cs`：新世界載入場景設定並驗證ID、入口、組織類型與格子。
- `config/scenes/sites.json`：上述七個場景的配置。主建築名稱與初始展示等級、每場景兩個可用／兩個鎖定格是可調原型配置，不是最終人口或容量平衡。
- `tests/Acceptance/SceneSiteTests.cs`／`Main.SiteSmoke.cs`：核心隔離與Godot場景整合驗收。

每個組織／聚落擁有獨立場景資料；同類可共用腳本與版型，不共用可變格子清單。只載入當前場景的顯示節點。場景顯示不推進Tick、不建立角色、不發放資源。

本次的進入／返回屬於顯示視圖切換，沒有新增權威角色SiteId或場景內尋路；使用資格仍由原世界位置與行動驗證決定。沒有將同一格的NPC全部宣稱為當前場景居民，也未新增抽象人口數值。

## 存讀與相容

場景配置是HexMap內的可選資料，沿用schema3快照保存；舊檔缺少Sites時為空，不在讀檔時讀取config或補資料。開新存檔才會載入最新場景配置。沒有修改舊檔、存檔政治資料、推測聚落歸屬或分配額外庫存。

主建築等級目前只用於格子顯示，沒有可操作的升級指令。內部空地不能施工、扣款或產出；既有世界格建造仍是原系統，不能將它誤認為內部格子已接線。
