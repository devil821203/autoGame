# 宗門清剿、組隊與經濟運轉驗收

2026-10-17。依使用者新增需求及兩項回覆實作；只在「宗門經濟／副本測試」情境啟用，不改正式地圖範圍。

## 清剿任務

- 自動發布清剿狼及清剿山匪，每輪各5隻，每隻共10貢獻點；數量／報酬／週期由`config/organizations/hunts.json`設定。本輪初值120Tick，第一次推進Tick即發布。
- 須在宗門接取，且必須仍是宗門成員。只計實際戰鬥勝利、目標種類相符、期限內且尚未滿額的擊殺；不以上交狼皮代替擊殺。
- 同一戰鬥只增加一次全宗門共享進度。小隊至少一人接取後，未撤退且仍屬該宗門的參戰隊員共享報酬；3人時10點按固定ID順序分4／3／3，總額不增加。未組隊則由接取者取得。
- 真實清剿收據可作考核成功依據；離宗清零、到期不發、滿額不超收、重複結算拒絕。記錄與點數發行帳本互相核對，存讀保留進度。

## 組隊與戰鬥

- 同宗門、同地點、健康且不忙碌的角色可邀請；必須由對方接受後才成立。最多3人（2～3人可進副本），設定在`config/combat/party.json`。
- NPC依自身戰鬥意願、健康、經濟機會與邀請資訊決定邀請／接受／集合，不由玩家跨角色操作。已同意隊伍的NPC會評估前往副本與等待集合，緊急治療可優先。
- 所有人須各自到副本，且健康／空閒，才能由隊長發起探索；不把隊員瞬移到隊長位置。採藥事件仍歸發起探索者，怪物事件才由全隊參戰。
- 沿用共同角色能力與戰鬥傷害公式：存活隊員各自攻擊、怪物每回合輪替攻擊一名隊員，每個人的生命／丹藥／強擊／撤退均獨立。成功撤退只移出本人，不強迫其他人撤退，撤退者不分本次戰利品與清剿點。
- 靈石按份額分配、餘數按確定順序給予；狼皮與丹藥不能切分，按確定輪替順序給一名參戰隊員。掉落仍從怪物實際庫存轉移，不複製成每人一份。每人獲得原有勝利經驗。
- 既有非永久死亡規則維持，生命最低1；本次驗證的是降低受傷，未加入永久死亡。三人與單人相同敵人的總受傷比較通過。
- 離宗／考核逐出時清理隊伍，低於2人解散；歷史戰鬥保存參戰快照，進行中戰鬥可存檔續跑。

## 經濟調整

先前160Tick實測：採藥0、產丹0、兌換0、2人逐出，顯示生產鏈沒有運作。調整以下測試設定，其他情境沿用原數值；舊存檔不自動套用。

| 項目 | 本輪測試值／目的 |
|---|---|
| 宗門初始成員 | 12名NPC加宗主，涵蓋四種志向；其他NPC仍自主生活，不強制轉職 |
| 初始供料 | 宗門另有40藥草、15丹藥，透過可稽核創世庫存建立 |
| 採藥 | 2Tick，成功每份4點 |
| 煉丹 | 3Tick、沿用1藥草配方與角色成功率，成功報酬120→30點 |
| 兌換 | 丹藥120點、藥草4點；靈石1:1購點，禁止反向，丹／草保留各10 |
| 俸祿 | 每10Tick每名成員30→10靈石，不含宗主；資金不足仍不挪用保留款 |
| 考核 | 30→120Tick，仍連續3期未成功才逐出，成功清零 |
| 物品任務 | 每20Tick檢查，丹／狼皮每單各5，期限120Tick；報酬120／15靈石維持原值 |
| 商店 | 藥草基價4、範圍2～8；丹藥基價120、範圍80～180 |
| 測試收購 | 每輪丹／狼皮各10、20Tick檢查、原無限外部測試資金維持 |
| 成員初期成長需求 | 此測試情境NPC目標修為60；獵手保留高戰鬥意願，其他角色有工作／成長動機 |

AI必要修正：不規劃用私人煉丹完成宗門專用設施情境的任務；保留需要自用的最後一顆丹，不反覆兌丹卻不服用；無成長需求者不優先購點換丹。可以用自有靈石補足購點缺額，回流宗門。健康的已組隊角色優先評估此次遠征，避免工作邀請讓隊伍永遠無法集合。成長效用倍率60及自用丹保留開關只在`economy/sect-production.json`啟用，沒有改動實際經驗／修為收益公式。

## 操作與限制

F5→「宗門經濟／副本測試」，或在此情境按「開新存檔（重設初始值）」套用新設定。推進一Tick發布清剿後，旅行至宗門，至「副本組隊與清剿」接狼／山匪任務。與同地點同門邀請組隊，等待對方同意；各自旅行到副本後，隊長按既有「探索打怪副本」。任務頁也提示清剿數量與入口。

目前多人協同僅涵蓋這次測試副本；沒有增加跨區傳送、永久死亡、玩家遙控隊員或其他副本玩法。無限外部收購仍是測試資金來源，因此這些結果是400Tick的功能運轉證據，不能宣稱封閉經濟長期平衡。人工視覺、長期運作與效能容量未驗證。
