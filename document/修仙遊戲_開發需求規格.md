# 自主修仙世界 — 遊戲開發需求規格

> 文件性質：需求基準與開發追蹤初稿（2026-10-16）  
> 狀態：核心方向已確認；細節及數值為候選方案，需逐步驗證。

## 1. 遊戲定位與核心體驗
- **類型**：2D 修仙題材、開放世界、角色/冒險模擬、策略放置、自主 AI 社會模擬。
- **世界模式**：持續運作的開放世界；玩家不操作的角色仍持續生活、修煉、交易、戰鬥及社交。
- **控制方式**：玩家僅直接操作自己建立或指定的角色；其他角色均由 AI 控制。玩家可藉組織政策、任務及獎勵間接影響其他角色。
- **核心特色**：玩家與 NPC 遵循相同規則，角色的獨立目標和互動自然形成經濟、社會與勢力變化，而非僅依預設劇本行動。

## 2. 核心循環
1. 角色依性格、天賦、志向、境界、功法、技能、需求與有限資訊評估現況。
2. 選擇目標（求生、修煉、賺錢、提升技能、社交、組織貢獻等）。
3. 規劃並執行行動（採集、購買、製作、出售、接任務、戰鬥等）。
4. 行動消耗時間與資源，改變財產、能力、關係、市場與世界狀態。
5. 角色根據實際結果與記憶重新評估，形成持續的自主循環。

## 3. 功能需求

### 3.1 世界與時間
- [ ] 世界地圖、地區、城鎮、宗門駐地、資源點。
- [ ] 世界時鐘與固定 Tick；長時間行動可排程完成。
- [ ] 資源再生、世界事件、事件通知與日誌。
- [ ] 玩家附近詳細運作、遠方簡化模擬；世界持續推進。

### 3.2 角色資料與成長
- [ ] 身分、組織、職位、生命/狀態、境界、功法、技能、熟練度、天賦、性格、志向。
- [ ] 需求（治療、修煉、財富、資源、安全、聲望等）、資金、物品庫存、裝備。
- [ ] 修煉、功法學習、技能升級、境界突破與資源消耗。
- [ ] 角色能判斷自己「可提供的服務/商品」與「所需的資源/能力」。

### 3.3 NPC 自主 AI
- [ ] Utility AI 對候選目標評分：經濟、成長、風險、社交、可行性及機會成本。
- [ ] GOAP 或可替換 Planner 規劃達成目標所需步驟。
- [ ] 個體差異：貪財、謹慎、忠誠、勤奮等性格；煉丹、戰鬥、採集等天賦與志向。
- [ ] 記憶與學習：記錄行動成本、收益、失敗、交易價格、關係變化；不等於全知世界資料。
- [ ] 環境改變時重新決策，但避免每秒全量重算。
- [ ] 玩家和 NPC 共用 ActionValidator / ActionExecutor。

### 3.4 生產系統
- [ ] 採集、種植（後續）、煉丹、煉器（後續）、配方、原料、品質與成功率。
- [ ] 生產消耗材料、時間與可能的費用；失敗造成實際損失。
- [ ] 角色可購料生產、出售成品、接單或尋找合作對象。

### 3.5 經濟系統
- [ ] 靈石與物品的持有、轉移、消耗及來源追蹤。
- [ ] 區域市場、商品庫存、供需、報價、交易紀錄與價格變化。
- [ ] NPC 估算成本、收入、利潤、失敗風險及機會成本。
- [ ] 價格上漲可能誘發採集、囤貨、轉職或停止生產；不可保證永遠有利可圖。
- [ ] 防止負庫存、超額成交、重複支付與不合理資源生成。

### 3.6 戰鬥系統
- [ ] 基礎屬性、功法、技能、傷害、受傷、消耗品與戰利品。
- [ ] NPC 自主判斷戰鬥、撤退、治療與資源準備。
- [ ] 玩家附近詳細戰鬥、遠方可簡化結算；具體玩家戰鬥操作方式待定。

### 3.7 社交系統
- [ ] 好感、信任、仇恨、師徒、合作、聲望與組織歸屬。
- [ ] 關係影響任務接受、交易、技能傳授、援助及衝突。
- [ ] 只儲存有意義的關係，避免每名角色與全世界角色建立完整矩陣。

### 3.8 組織系統
- [ ] 宗門、國家、門派等組織及其資金、物資、成員、職位。
- [ ] 招收弟子、手下與人才；組織政策、獎懲、職責及任務發布。
- [ ] 玩家若為首領可設定生產需求、報酬、期限與政策；NPC 自行判斷是否接取。
- [ ] 任務支援多人分批交付、庫存驗收、支付、預算控制、期限與取消。

## 4. 代表性情境：回春丹宗門任務
**宗門任務**：回春丹 20 顆；報酬 120 靈石/顆；期限 7 天；總報酬上限 2,400 靈石。

**初始示例**：市場售價 110/顆；原料成本 65/份；宗門有 10,000 靈石、5 顆回春丹；市場有 50 份原料。

**角色示例**：

| NPC | 身分與性格 | 煉丹成功率 | 初始資金 | 可能決策 |
|---|---|---:|---:|---|
| 林青玄 | 勤奮、理性、丹道志向 | 95% | 1,200 | 接單煉丹 |
| 趙萬財 | 貪財、投機 | 85% | 3,000 | 比較市場與宗門利潤後接單 |
| 蘇若蘭 | 謹慎、忠誠 | 90% | 800 | 重視宗門貢獻而接單 |
| 陳小竹 | 好學、資金少 | 65% | 300 | 可能先學習或籌資 |
| 韓山 | 務實採藥師 | 不會煉丹 | 200 | 轉而採集出售原料 |
| 莫無鋒 | 好戰劍修 | 不會煉丹 | 600 | 不接單，可能購買丹藥 |

**計算示例**：成功一顆的長期預期原料成本 = 原料單價 ÷ 成功率；預期毛利 = 報酬 − 預期原料成本。此公式不含時間、交通、機會成本，也不代表單次實際結果。NPC 應根據實際交易價格、庫存與失敗次數調整策略。

**驗收行為**：不同 NPC 做出不同選擇；煉丹者購入原料並交付丹藥；採藥師受需求影響；宗門付款且丹藥庫存增加；市場供需改變；沒有超額收購、重複支付或物品憑空產生。模擬結果允許因亂數與市場條件而不同。

## 5. 技術架構（建議）
- 引擎與語言：Godot 4 + C#。
- 核心層：WorldState、GameClock、SimulationScheduler、Character、Organization、Inventory、Market、Relationship。
- AI 層：NeedEvaluator、GoalSelector、UtilityScorer、ActionPlanner、MemorySystem。
- 行動層：ActionIntent、ActionValidator、ActionExecutor、ActionResult。
- 系統層：Production、Cultivation、Combat、Economy、Social、Organization、Event。
- 呈現層：2D 地圖、角色、介面、事件與交易紀錄；不直接決定世界規則。
- 持久層：存檔、讀檔、世界快照、必要事件歷史；儲存方案待定。

## 6. 效能與規模
- 目標是逐步驗證 100 → 1,000 → 5,000 → 10,000+ NPC，並非保證可在任意硬體上達成。
- NPC AI LOD：附近高頻詳細、同區低頻、遠方排程/批次結算。
- 事件驅動：僅通知相關角色；使用待決策佇列、合併重複事件與計算預算。
- 社交採稀疏關係；交易與地區查詢使用索引，避免全角色兩兩比較。
- 遠方角色仍有個體狀態與可追溯結果，不應直接失去獨立性。
- 效能監測：Tick 時間、AI 決策次數、事件量、記憶體、FPS、模擬時間倍率。

| 階段 | 功能 | 完成條件 | 狀態 |
|---|---|---|---|

| 1 | 30–50 NPC、需求/性格/技能、採集、煉丹 | NPC 能自主完成生產循環 | 未開始 |

## 8. 重要驗收準則
1. 玩家與 NPC 行動規則一致，NPC 不享有隱藏資源或全知市場資訊。
2. 資源、靈石、庫存及任務預算守恆；失敗、取消、過期、並發都能正確處理。
3. 角色會因性格、技能、需求、資金及經驗做出可解釋的不同決策。
4. 不需要玩家指令，NPC 也能自主採集、生產、交易、消費與提升技能。
5. 組織政策與任務會改變 NPC 誘因，但不直接剝奪 NPC 自主權。
6. 世界在玩家不介入時仍推進；相同種子與輸入可重現結果。
7. 所有效能目標以實際測試判斷，不以估算值替代。

## 9. 尚待決定事項
- [ ] 戰鬥呈現：全自動、玩家可手動、或混合。
- [ ] 世界時間倍率、暫停/加速、玩家離線時是否推進。
- [ ] 地圖規模、地形、旅行方式與移動時間。
- [ ] 境界、功法、靈根、天賦及技能的完整數值規則。
- [ ] NPC 生老病死、繁衍、繼承及永久死亡。
- [ ] 市場機制：訂單簿、固定商店或混合；價格上下限與貨幣來源。
- [ ] 組織治理：招募、任免、叛逃、勢力外交與戰爭。
- [ ] 玩家能否切換指定角色、切換限制與角色死亡後規則。
- [ ] UI 美術風格、解析度、操作方式、存檔格式及發行平台。
- [ ] MVP 目標硬體、FPS 與模擬時間倍率。
