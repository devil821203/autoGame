# 青雲宗場景：實作與驗收

更新：2026-10-17。限定首個據點色塊場景，其他四個據點與正式地圖不在本次實作範圍。

## 如何觀看

1. 用 Godot 4.3 .NET 開啟 `src/Presentation/project.godot`，按 F6 執行 Main 場景或 F5 執行專案。
2. 按「宗門經濟／副本測試」建立測試世界。這會重建目前世界，既有進度請先另存。
3. 選擇第一個頁籤「青雲宗場景」，按「前往青雲宗」。
4. 按「前進一 Tick」提交旅行，再前進 3 Tick，或按繼續等候抵達。
5. 抵達後可見金色玩家、藍色同據點角色。點「任務告示牌」「宗門兌換處」「宗門大殿」開啟既有操作頁，點回「青雲宗場景」返回。
6. 點藥園、煉丹房或山門出口會排隊旅行；推進 Tick 執行，旅行期間場景設施停用。

場景也可用於階段4 Demo，但宗門工作與兌換須使用具備對應規則的宗門經濟情境。既有面板會顯示資格／設定限制。

## 實際變更

- `src/Presentation/Scenes/Areas/QingyunSect.tscn`：可獨立編輯的 Node2D 場景資源，由主介面載入。
- `src/Presentation/SectCourtyard.cs`：色塊山門、廣場、大殿、設施按鈕、角色站位與玩家標記。
- `src/Presentation/SectScenePanel.cs`：場景容器、玩家位置／旅行／資源提示、指令與面板入口。
- `src/Presentation/Main.cs`：新增第一個場景頁籤，沿用單一引擎及既有操作頁；統一 Render 同步快照。
- `src/Presentation/Main.SectSceneSmoke.cs`：場景整合驗收。

場景只呈現玩家同據點角色；不在青雲宗時保留建築預覽，隱藏人物並停用設施。場景不修改 Domain、不新增座標或規則、不產生物品。畫面角色目前為依 ID 排序的靜態站位，尚無行走動畫或點人物觀察功能。

## 實際驗收

```powershell
dotnet build src/Presentation/CultivationGame.csproj --no-restore
& '.tools/godot43/Godot_v4.3-stable_mono_win64/Godot_v4.3-stable_mono_win64_console.exe' --headless --path src/Presentation -- --sect-scene-smoke
```

- 建置：0 警告、0 錯誤。
- `SECT_SCENE_UI_SMOKE_PASS`：顯示不改變世界摘要、遠端人物隱藏／互動停用、抵達時機、任務與兌換面板連接、存讀一致、出口旅行。
- `SECT_FACILITY_UI_SMOKE_PASS`：既有工作資格、旅行、宗門採藥、貢獻、兌換、購點與存讀回歸通過。
- `MAP_UI_SMOKE_PASS`：既有旅行、排程與存讀回歸通過。
- Headless 啟動並運作 3 幀，程序正常結束，未輸出場景或繪圖錯誤；不視為人工視覺驗收。

保留失敗紀錄：首輪建置新驗收檔缺少 Simulation 命名空間造成 4 個 CS0103，已修正；首輪場景測試發現 Refresh 放錯方法，遠端按鈕未停用，已修正並重驗通過。
