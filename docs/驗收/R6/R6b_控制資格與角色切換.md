# R6b 控制資格與角色切換檢查點

日期：2026-10-31；狀態：已完成（僅本次已確認測試範圍）。使用者轉進R7後補跑完整回歸431/431通過。

新建獨立情境由 `config/characters/player-control.json` 授權玩家及既有功法修練NPC；關係不自動授權。暫停且雙方非戰鬥時免費切換，工作與資產留在原角色，原角色交給AI，切換後關閉玩家自主排程。忙碌角色可被選取，但不能重複開始工作。

撤銷或非戰鬥時角色生命歸零，停止世界推進及玩家指令，等待手選合格角色；無合格者提供讀檔或新局。觀察其他NPC不改控制資格。撤銷按鈕僅為本測試情境的可信測試入口，不是正式資格取得玩法。戰鬥失能不視同死亡，不能藉切換跳過戰鬥限制。

控制資料與授予／撤銷／切換歷史保存於格式10，新內容版本r6b-1；舊情境與舊檔不自動啟用。核心驗證、事件推進及UI共用控制判斷；原已接受工作可由原角色完成，不轉移所有權。

聚焦驗收13/13，涵蓋越權、免費切換、保留工作、AI接手、撤銷暫停、存讀與新局重設。第一輪12/13的AI接手等待窗口不足，按既有決策預算調整觀察窗口後通過，未改AI權重。UI先發現AP快照不存在的Single例外，改用共用每日AP規則呈現初始預算後，Godot檢查點exit0。
