# R3-01 風險狀態與藥效通知（2026-11-15）

## 目標與實作

接續 [R3 執行方案](../../方案/R3_事件決策與知識邊界_執行方案_20261110.md) 的需求／風險與戰鬥狀態觸發。戰鬥結算與釋放已有 ActionCompleted，本批補實際狀態變更的 StateChanged，讓直接受影響角色保留重新評估原因。

- `LifeActions.Effects`：持續藥效實際回復生命（heal > 0）才通知該角色；滿血或失能時沒有生命變化，不通知、不復活。
- `BoardBattleActions.Advance`：有效攻擊扣除目標生命後通知受傷者。既有有效目標須仍有生命，傷害至少為一，因此此處代表真實生命變更；等待／無效攻擊不發出受傷通知。
- `EquipmentDurabilityActions.Wear`：實際耐久下降後通知持有者。原先同戰鬥只磨損一次、耐久為零不再磨損的早退保留，不重複發通知。

Request 只加入直接角色的佇列，不廣播給旁觀者。參戰者仍由既有忙碌判斷及玩家戰鬥凍結擋住世界 Planner；通知保留至完成／釋放。未調整戰鬥 AI、傷害、生命、治療、藥效次數、耐久損失、AP 或費用，沒有新增 config 數值或存檔欄位。

## 驗收

`tests/Acceptance/EventDecisionTests.cs` 新增四項：

1. NPC 透過原有行動使用止血散，首次脈衝前不喚醒，實際回血後只有本人取得 StateChanged，快照續算 digest 相同。
2. 滿血／失能 NPC 的藥效結算不改生命、不喚醒，也不復活。
3. 真實棋盤等待回合不通知；有效攻擊通知參戰者，非參戰者不收到；玩家戰鬥期間 AdvanceTo 停於 PlayerBattle，外部世界 Planner 呼叫數為零；快照後續回合一致。
4. 真實製作及裝備鐵劍，第一次攻擊磨損並通知持有者；同戰鬥後續攻擊不再磨損或通知未變更的裝備狀態。
