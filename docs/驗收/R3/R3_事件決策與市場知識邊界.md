# R3 事件決策與市場知識邊界

2026-10-31。使用者授權繼續R3；本次限定為事件喚醒核心與本地公開市場觀察轉接。R1／R2未完成範圍仍保留，沒有進入R4。

## 已接範圍

明確啟用的新R3世界在R1秒時鐘、R2生命週期上保存`Time.EventDecisions`。既有主要情境與舊存檔不自動啟用。Godot測試情境區新增「R3事件決策測試（重建）」；主角仍透過原勾選項選擇自主排程。

`DecisionRequest`按角色去重並合併原因，以請求序號排序；工作完成、中斷、服務雙方、休息完成、戰鬥結算及已知資源通知可產生定向喚醒。無可行行動時，將重試寫入秒制事件佇列；提前通知使舊重試版本失效。沒有待決策請求時不進入原候選集合建構器。工作中的角色不做完整重評，由完成／中斷事件喚醒。

沿用原UtilityPlanner、專職／功法／組織選擇、資格驗證、費用及收益；只改呼叫時機。決策預算仍以相容步長為窗口，未處理請求保留序號，不能被新請求插隊。`Evaluations`計實際交給選擇器的角色數；`PlannerCalls`另外計基礎Planner實際呼叫數，專職／生存分流不冒充Planner呼叫。診斷的Decisions不再使用提交結果數代替。

`DecisionTrace`保存最後一次觸發原因、實際候選分數、共用驗證器拒絕原因、選中指令與市場知識來源。這是最後一次評估快照，尚非完整永久決策歷史。

## 知識邊界與限制

`ActorKnowledge.ReadMarket`只讓同區且身在城鎮的角色讀取公開報價／上架庫存，保存觀察地點、秒數、有效期、來源與可信度。離開後只能讀取同區未過期的記憶；未觀察者只可使用config公開基準價與零已知庫存，不讀即時遠地庫存。基礎觀察不再暴露商人的真實錢財，改以已知公開收購價判斷單件報價，最終是否能支付仍由共用交易驗證器檢查。

可信度1表示直接目擊公開資料，不是新增AI權重。報價在觀察時可能過時，記憶不會因其他角色私有資產變化而自動刷新。

**R3整體仍為測試中**：尚未把採集地庫存、所有專職／組織策略、社交公告、風險與需求變化逐條改走ActorKnowledge；實際喚醒時原選擇器仍會建區域索引。不能宣稱完整有限知識、全面增量索引或全世界純離散事件已完成。R1其餘活動／週期仍由相容事件推進；R2其餘一般生產／建造轉接缺口不變。

## 設定與相容性

沒有新增平衡數值或改AP／經驗。重試讀`config/time/action-driven.json.IdleRetryTicks`；啟用LOD時取其與既有`config/world/performance.json`區域重試間隔的較大值。預算讀`config/economy/production.json`載入的世界`Rules.DecisionBudget`，市場記憶有效期讀`Rules.MemoryTicks`並按該世界每步秒數換算；均使用已載入快照，改config須重建。來源與型別識別字為工程常數。

R3 JSON外部格式6，內部WorldState仍沿用既有schema3；必須同時包含R1／R2／R3資料。格式1～5含R3資料會拒絕，避免舊引擎靜默丟棄待決策、重試與知識。舊檔不遷移、不覆寫；資料完整性檢查拒絕非法角色、序號、觸發、重複重試及偽造觀察來源。
