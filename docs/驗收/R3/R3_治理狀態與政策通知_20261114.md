## 治理變更

`GovernanceActions.Execute` 原本只更新職位、會籍或政策，主要依行動者終態喚醒。現補：

- 任命、降職、驅逐：直接變更的角色收到 StateChanged；不向其他成員廣播私人任免。
- 自行加入／退出：本人收到 StateChanged，該組織現任領袖收到 KnownNotification，來源是該組織實際會籍變更。
- 公開政策實際變更：沿現行自主決策的同區政策觀察範圍，通知一般存活角色（含同區非成員），不通知遠地觀察者或怪物。
- 相同政策：保留原執行與事件記錄，但不重複喚醒觀察者；遭拒的治理指令不通知目標。
- 獎勵仍沿用前批共用資源入帳通知，不另加一套付款通知。

所有通知仍交由 Request 去重、FIFO、預算與忙碌保留處理，不直接執行 Planner 或指令。原治理資格、職位、費用、容量、社交影響與 AP 不變，沒有新增 config 或存檔欄位。
