# R3-01 任務事件觸發與公告邊界（2026-11-14）

## 目標與變更

接續 [R3 執行方案](../../方案/R3_事件決策與知識邊界_執行方案_20261110.md) 的任務狀態改變觸發。原先手動發布、交付及取消／到期主要只有行動者終態喚醒；週期公告則無條件喚醒所有宗門成員，兩條路徑不一致。

`MissionActions.Notify` 現在由共用發布、交付（含部分及完成）、取消／到期關閉流程呼叫，在狀態與帳本更新後加入 KnownNotification：

- 同區公告板讀者依現行 `AutonomousDecisions` 的區域與成員資格規則篩選；公開任務可通知同區非成員，成員任務不通知無關非成員。
- 已接單者依既有 Participants 紀錄知道自己的任務更新，即使之後旅行至其他區域或離開組織，也會收到進度／關閉觸發；這不讓未接單的遠地角色取得公告。
- 僅一般存活角色收件，不通知怪物。收件順序按角色 ID 固定，沿用 Request 去重與原 FIFO；不直接呼叫 Planner 或替 NPC 提交行動。

`WorldPeriodEvents` 的宗門週期公告改依共用發布流程通知，不再另外喚醒整個宗門。自動公告沒有新任務時，不會僅因公告週期到達就喚醒所有成員。

接單動作本身沿用 R2 行動終態喚醒行動者，不廣播私人接單操作。未修改價格、預算、期限、費用、交付上限、退款、資格或存檔格式，沒有新增 config 數值。

## 檔案

- `src/Simulation/MissionActions.cs`：共用任務通知。
- `src/Simulation/WorldPeriodEvents.cs`：移除宗門公告的無條件成員喚醒。
- `tests/Acceptance/EventDecisionTests.cs`：新增四項任務案例，隔離既有社交到期測試的週期公告來源。

## 驗收

1. 公開／成員任務發布：本地成員收到通知，非成員僅收到公開公告，未接單遠地角色不收到。
2. 真實接單後跨區：取消及精確到期通知原參與者，不通知其他遠地角色或私有任務的無關非成員；到期快照續算一致。
3. 分批交付至完成：本地公告觀察者能收到剩餘數量更新，遠地無關者不收到；付款與已交數量仍依原規則。
4. 週期自動公告：走共用通知流程，不越過同區／成員邊界。
