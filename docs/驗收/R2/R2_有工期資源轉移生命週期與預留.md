# R2 有工期資源轉移：生命週期與預留

2026-11-04。本批限定最新獨立世界秒制情境、`DurationTicks > 0` 的既有資源轉移；不新增取消政策，也不調整零工期轉移。

## 行為

- 原本有工期轉移即會在開始時把發送者的資源放入 escrow；本批將該筆既有帳本異動連結 R2 行動與資源預留，記錄收件對象，沒有另建庫存。
- 到期前資源維持在 escrow；到期時交付原指定收件者、核對並完成行動，舊完成事件不能重複交付。玩家與 NPC 共用同一流程。
- 個別製作裝備及既有獨立武器在轉移預留期間仍計入其合法持有總量；交付後保留原物品 ID、品質與耐久。只計入已驗證的執行中轉移預留。
- 檢查存檔中的收件者、預留、待完成工作與帳本。原始時間、數量、AP、容量檢查及交付規則不變。
- `DurationTicks == 0` 的原延後指令仍在完成時扣資源，本批沒有改成預留；歷史非獨立世界事件情境也沿用原流程。
- 最新秒制情境外部存檔格式由 22 更新為 23；按使用者指示不轉換或覆寫舊檔。未新增或調整任何 config 遊戲數值。
