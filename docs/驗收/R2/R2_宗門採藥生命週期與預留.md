# R2 宗門採藥：生命週期與資源預留

2026-11-04。本批只處理最新獨立世界秒制情境的既有宗門採藥；沒有新增任務或啟用煉丹。

## 實作範圍

- 玩家與 NPC 均須是宗門成員並先接受既有採藥工作；合法開始時建立 R2 行動，從原藥園帳戶將一份藥草保留至既有 escrow，預留紀錄以權威帳本為準。
- 完工後交付宗門庫存、計入既有工作紀錄與貢獻點，並將行動標記完成；再次執行舊完成事件不能重複發放。
- 若角色工作中途退出宗門，依原規則仍將已保留藥草交給宗門，但不再取得貢獻點。未新增取消或中斷政策。
- 快照驗證核對行動、預留、藥園扣除、宗門收取及工作紀錄；歷史非獨立世界秒制情境仍沿用原流程。
- 採藥成本、工期、貢獻點及產出仍來自現有 config／世界設定快照，沒有新增或更改遊戲數值。最新外部存檔格式由 21 改為 22；遵照使用者指示不轉換或覆寫舊存檔。
