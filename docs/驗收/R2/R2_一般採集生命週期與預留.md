# R2 一般採集：生命週期與資源預留

2026-11-03。本批只轉接既有一般採集，不新增玩法或取消行動。其他一般生產、宗門工作、建造及既有取消入口仍為 R2 後續項目。

## 行為與資料

- 最新獨立世界秒事件情境中，玩家與 NPC 透過既有驗證後，建立同一套 R2 行動實例：開始記錄、預留、執行與完成。
- 採集開始從該區域現有資源帳戶移入原有 escrow，`ResourceReservation` 引用該帳本異動，不建立另一個庫存。原 AP、體力、採集時間、數量、經驗與地區規則保持不變。
- 完工前核對行動及版本，依原 `Gathered` 帳本紀錄把藥草交給採集者；紀錄一次完成與終態，無法重放取得第二份。完整性驗證核對任務、資產預留、資源扣款與交付。
- 保留歷史情境原採集模式。最新情境因進行中的一般採集新增必要快照資料，存檔格式由 19 提升為 20；遵照使用者指示不轉換舊存檔，也不修改舊存檔。
- 本批不改 `config/` 遊戲參數，不為測試新增遊戲數值。
