# R2 既有行動批次整合（尚未編譯或測試）

依使用者要求，本批僅修改程式，未執行編譯、專項測試、完整回歸或 Godot 驗收；下列是程式修改範圍，不是已驗收功能清單。

- 既有獨立秒制世界的社交邀請與回應、互助及師徒學習、組織治理、聚落與組織據點操作、外部市場、人口投入、招募及派工、六角建築取消、副本探索，接入 R2 共用行動狀態，按原延時路徑到期驗證及執行；沒有新增物品或資金的提前預留。
- 免費等待接入共用狀態，仍沿用設定的等待時間及零 AP。休息接入既有恢復事件，依現有恢復結果完成或中斷；未修改生命、體力及 AP 恢復數值。
- 加入上述動作的待處理工作與行動狀態、完成／失敗事件一致性檢查；既有已接入的修練、生活服務、旅行、任務、宗門、商店、組隊與清剿流程保留。
- 非獨立秒制世界維持原路徑；不遷移舊存檔。戰鬥回合與戰鬥用藥仍使用既有戰鬥流程，原本停用的煉丹及耗丹行動維持停用，沒有新增未確認的材料損失、設施容量或取消規則。
